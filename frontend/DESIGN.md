# FourthMatch frontend: design system (v2)

Audience: hackathon judges and a CFO. The product should read like an Apple product page on the
landing and like a calm, precise tool inside the app. Typography and real imagery carry the
design; colour is reserved for meaning. Live spec sheet: `/styleguide`.

## Principles
1. **One surface rule.** Elevation by *fill*, never by line + shadow together.
   White cards (`bg-fm-panel`) sit on the grey page (`bg-fm-bg`); grey tiles (`bg-fm-tile`,
   `bg-fm-raised`) sit on white. Hairlines (`border-fm-border`) only divide content *inside* a
   surface. Shadows (`shadow-fm-float`) only on floating layers: nav sheet, palette, menus.
2. **One accent.** `fm-accent` (#0071E3 light / #2997FF dark) for links and the primary CTA.
   Nothing else is blue. No gradients as decoration, no glow, no purple, no emoji, no sparkles.
3. **Colour means state.** Status colours appear only with a glyph shape and a text label.
4. **Real media only.** Frames and loops come from the project's own videos and model outputs
   (`public/media/`). `synthetic_muse_image.webp` (muse-image-1.0) is only ever shown labelled
   "Synthetic — generated by Muse Image" and never as evidence.
5. **No invented numbers.** Every count, rupee amount and verdict comes from the API (or the MSW
   dataset built from repo data files). If a value was not measured, show "—".

## Type
- **Inter** (self-hosted variable woff2 in `public/fonts`, no third-party requests) for display
  and UI. Headlines use tight tracking (-0.022 to -0.038em) and `text-wrap: balance`.
- Scale classes: `.fm-hero` 48→104px, `.fm-display` 40→80, `.fm-title` 32→56,
  `.fm-headline` 24→32, `.fm-lede` 19→24, `.fm-body` 17, UI 14, `.fm-caption` 12.
  App page titles: 34→40px via `<PageHeader>`.
- **`.fm-figure`** for display-size figures (40px and up): Inter with tabular numerals. Plex Mono
  at 100px reads as a terminal, so big numbers use SF-style tabular Inter instead.
- **IBM Plex Mono** (`font-mono`, tabular, self-hosted) for IDs, hashes, inline and table
  quantities and rupees, model names.
- Money: `<Money paise/>` / `formatINR` (en-IN, ₹12,45,000). Quantities: `<Qty/>`. Never by hand.
- Labels: `.fm-label` is sentence case, 12px semibold, muted. No uppercase condensed labels.

## Layout
- 8px rhythm. Landing column: 1200px, 12-column grid, 24px gutters, sections `py-32` (`py-24`
  on mobile). App column: 1440px, `px-4 sm:px-6 lg:px-8`. The nav matches the column it sits over.
- Reserve aspect ratios for every image (`width`/`height` attributes + `aspect-*`). Below-the-fold
  media is `loading="lazy" decoding="async"`.
- Must work at 1440x900 and 390x844 with no horizontal scroll.

## Motion (src/lib/motion.ts, no animation library)
- `useReveal()` + `.fm-reveal` (600ms ease-out fade/translate on first view, `--fm-delay` stagger).
- `useScrollProgress(ref)`: rAF-throttled 0..1 progress through a tall section. Drives the
  sticky story (`pages/landing/Story.tsx`) and the SAM wipe.
- `useScrollFrame(fn)`: per-frame scroll callback for direct style writes (hero parallax).
- No count-ups. Money is never tweened: the computed figure appears with `.fm-appear` (fade + settle).
  Live object counts (`LiveCounter`) step only through integers the pipeline actually observed
  (one per stored `tracking_progress` event / SAM track), each sliding in with `.fm-tick`. Easing `--fm-ease` = cubic-bezier(0.22, 1, 0.36, 1),
  durations 200–600ms.
- `prefers-reduced-motion`: reveals render visible, parallax and wipes are off, the story renders
  as stacked static sections with final values, the hero loop does not autoplay.

## Shell
`TopNav` (frosted, sticky; `overlay` = transparent over the landing hero; mobile menu sheet),
`StatusBar` (slim footer: API state, Meta models, policy version, IST clock), `CommandPalette`,
`useGlobalKeys` (`/` or ⌘K palette, `g 1-5` pages, `t` theme).

## Components (src/components/ui)
Button (variant accent|primary|secondary|ghost|link|hold|verified|danger, size xs|sm|md|lg|xl|icon,
asChild; all pills), Panel (title inside the padding, no header divider), PageHeader, KpiStrip, KpiTile
(figure first, then label), Spark, StatusBadge, SignalGlyph, Money, Qty, Tag(tone), Kbd, DataTable
(`rowHeight="auto"` for rich rows), Stepper (horizontal by default; `progressIndex`), FourMatchStrip
(four large tiles, `surface` raised|panel), FourMatchMini, LiveCounter, DeliveryThumb (real frame or
"Paper" tile), LoadDiagram, EmptyState, ErrorState, Skeleton, SkeletonRows. Segmented controls and the
queue view toggle use `.fm-thumb` (white thumb on a grey track); inputs use `.fm-field`. Dialogs use
`.fm-overlay` + `.fm-sheet` (centred sheet, bottom sheet on phones) or `.fm-pop`. Brand: BrandMark, Wordmark (shell/BrandMark).
Chart colours: read CSS vars via `chartTheme()` / `cssVar()` in src/tokens/tokens.ts.

## Every page
Loading skeleton, error state and empty state. Data via TanStack Query + `api` (src/lib/api.ts),
types in src/types/api.ts. Copy: short, declarative, specific, sentence case. No filler.

## Media pipeline (public/media)
Scenario frames are mapped in `src/lib/media.ts` (`SCENARIO_FRAMES`, `frameFor`) and used as video posters,
queue thumbnails and the PO picker; never as evidence on their own.
Frames: `ffmpeg -ss <t> -i public/demo/<scn>.mp4 -frames:v 1 -c:v libwebp -quality 80`.
Hero loop: 7 s of scn2_short, 1280px, no audio, H.264 (crf 22, faststart) + VP9 WebM (crf 31),
poster WebP. SAM still: `samples/cartoon.jpg` and `samples/out/carton_overlay.png` → WebP.

## Demo build
`IS_MOCK` (src/lib/demo.ts, `VITE_MOCK=1`) serves every endpoint from MSW. The mock dataset has no
real evidence-pack files, so no hash is ever shown as sealed in that build: `EvidenceSeal` and the
landing verdict show `DemoSealNote` ("Demo build — evidence packs are sealed … on the live server").
